KPI 분류 판단 흐름도
위에서부터 순서대로 질문하고, 처음으로 YES가 나오는 목표로 분류합니다
하나의 KPI가 여러 목표에 해당하는 것처럼 보여도, 이 흐름도의 순서를 따라 먼저 해당하는 목표 하나에만 분류합니다. (글로벌 여부 → 금액 → 고용 → 사업화 → 제작 → 교육 순으로 확인)
1
🌐 결과물이 해외(수출·협력·진출)와 연결되는가?
YES → ⑦ 글로벌 성과 NO → 다음 질문으로
2
💰 금액으로 측정되는가? (매출 또는 투자유치)
YES → ③ 매출액 또는 ④ 투자유치 NO → 다음
3
👥 채용(취업)이 발생했는가? (4대보험 기준 신규 채용)
YES → ⑤ 일자리 창출 NO → 다음
4
🚀 콘텐츠·IP·창업이 시장에 나왔는가? (출시·법인 설립·계약 완료)
YES → ⑥ 사업화 건수 NO → 다음
5
🎬 콘텐츠 결과물이 실제로 제작되었는가? (영상·게임·웹툰·음악 등)
YES → ② 콘텐츠 창·제작 NO → 다음
6
🎓 직무 특화 교육을 이수했는가? (수료증 발급 가능한 직무과정)
YES → ① 전문인력 양성 NO → 다음
7
위 6가지에 모두 해당 없음
부서 자체 KPI — 경영목표 집계 제외
ℹ️ 부서 운영상 필요한 KPI이지만 7대 경영목표에 해당하지 않는 경우 부서 자체 관리 지표로 입력합니다.

주요 준수사항
실적 입력 시 반드시 지켜야 할 규칙입니다
실적은 완료된 건만 입력
해당 기간 내 실제 완료된 건수·인원·금액만 입력합니다. 예정·계획·진행중은 입력 불가합니다.
정해진 단위 준수
KPI 등록 시 정해진 단위(명/건/백만원 등)를 반드시 사용합니다. 임의 단위 변경 금지. 단위 변경이 필요하면 경영혁신본부에 문의.
전문인력 양성: 수료증 기준
교육 참가자 중 수료증 발급 기준으로만 집계합니다. 체험·관람 행사, 1~2일 단기 교양교육은 제외합니다.
일자리: 4대보험 기준
4대보험 가입 신규 채용만 해당합니다. 인턴은 정규·기간제 전환 시점에 집계. 봉사·단기 프리랜서 제외.
사업화: 시장 출시 완료 기준
출시·법인 설립·계약 완료 시점에 집계합니다. 시제품 단계·사업계획서 제출만으로는 집계 불가합니다.
매출/투자: 민간 거래만
외부 민간 판매·민간 투자만 집계합니다. 정부 보조금, 지자체 지원금, 대출금은 전부 제외합니다.
글로벌: 실질 해외 연결만
해외 수출 계약·MOU·박람회만 해당합니다. 국내 행사에 외국인 참가, 해외 출장·벤치마킹은 제외합니다.
마감 내 입력 원칙
각 주기(월·분기·반기·연) 종료 후 2주 이내에 입력합니다. 이후 수정이 필요하면 경영혁신본부 승인 후 처리합니다.

자주 묻는 질문 (FAQ)

Q
하나의 사업이 여러 경영목표에 해당할 것 같은데 어떻게 하나요?
하나의 사업에서 여러 결과가 발생할 수 있습니다. 이 경우 결과 유형별로 별도의 KPI를 등록합니다. 예를 들어 창업 지원 사업에서 교육도 하고, 창업도 이어졌다면,
  • 교육 수료자 수 → ① 전문인력 양성
  • 창업 법인 설립 수 → ⑥ 사업화 건수
  • 신규 채용 인원 → ⑤ 일자리 창출
같은 사업명으로 여러 KPI를 등록할 수 있습니다. 각각 별도로 입력하세요.
Q
실적을 잘못 입력했어요. 어떻게 수정하나요?
KPI 입력 탭에서 해당 KPI의 「실적 입력」 버튼을 다시 클릭하면 기존에 입력한 값이 표시됩니다. 값을 수정한 후 저장하면 됩니다.
이미 보고서에 포함된 과거 데이터를 수정할 경우, 경영혁신본부에 사전 공유 후 수정해 주세요.
Q
교양 강의도 전문인력 양성으로 집계해도 되나요?
안 됩니다. 전문인력 양성은 다음 3가지 조건을 모두 충족해야 합니다:
  1. 취업·창업·사업화로 이어지는 교육
  2. 특정 직무·기술에 특화된 커리큘럼
  3. 수료증 또는 이수 확인 가능
일반 시민 대상 교양교육, 1~2일 단기 강의, 체험·관람형 행사는 포함되지 않습니다.
Q
정부 지원금을 받은 기업의 매출도 집계하나요?
지원금 자체는 매출이 아닙니다. 그 기업이 지원금을 바탕으로 제품·서비스를 만들어 외부 민간 시장에 판매하여 발생한 수익이 매출입니다.
  • 정부 보조금, 지자체 지원금 → 매출 아님 (제외)
  • 고객에게 판매한 금액 → 매출 (포함)
Q
달성률이 100%를 넘어도 되나요?
네, 100% 초과 달성이 가능합니다. 시스템에서는 달성률이 100%를 초과해도 「달성」으로 표시됩니다. 예를 들어 목표 10명 대비 실적 15명이면 달성률 150%로 표시됩니다.
Q
해외 박람회 참가도 글로벌 성과로 집계하나요?
참가 자체는 글로벌 성과에 포함됩니다. 단, 글로벌 성과의 단위는 만달러(수출 금액)이므로, 박람회 참가를 통한 수출 계약 금액이 발생한 경우에 집계합니다. 단순 참가(계약 없음)는 별도 부서 자체 KPI로 관리하거나 경영혁신본부와 협의하세요.
글로벌 성과 KPI의 단위가 만달러가 아닌 경우(건수 등)라면 KPI 등록 시 단위를 확인하세요.
Q
연간 목표를 중간에 변경해야 할 경우 어떻게 하나요?
KPI 목표치 변경은 경영혁신본부 승인 후 처리합니다. 임의로 목표를 변경하면 전체 경영 목표 집계에 영향을 미치므로, 반드시 사전 협의 절차를 거쳐야 합니다. 변경이 필요한 경우: 담당자 → 경영혁신본부 협의 → 시스템 수정 순서로 진행합니다.
Q
시스템 접속이 안 되거나 오류가 발생하면?
  1. 브라우저 새로고침 (F5 또는 Cmd+R) 시도
  2. Chrome 또는 Safari 최신 버전 사용 권장
  3. URL 재확인: kpi-dashboard-zeta-lyart.vercel.app
  4. 위 방법으로 해결 안 될 경우 경영혁신본부에 문의
