Q
하나의 사업이 여러 경영목표에 해당하는 것 같아요
결과 유형별로 별도 KPI를 각각 등록합니다. 예를 들어 창업 지원 사업이라면:

🎓 교육 수료자 → ① 전문인력 양성
🚀 창업 법인 설립 → ⑥ 사업화 건수
👥 신규 채용 → ⑤ 일자리 창출

같은 사업명으로 여러 KPI를 등록할 수 있습니다.
Q
실적을 잘못 입력했어요. 수정할 수 있나요?
「실적 입력」 버튼을 다시 클릭하면 기존값을 수정할 수 있습니다.
⚠️ 이미 보고서에 포함된 과거 데이터 수정 시, 경영혁신본부에 사전 공유 후 수정해 주세요.
Q
교양 강의도 전문인력 양성으로 집계할 수 있나요?
안 됩니다. 수료증 발급이 가능하고, 특정 직무·기술에 특화된 과정이어야 합니다. 일반 교양강의·체험 행사는 제외됩니다.
Q
정부 지원금을 받은 기업의 매출도 집계하나요?
지원금 자체는 매출이 아닙니다. 지원금을 바탕으로 제품·서비스를 만들어 외부에 판매한 수익이 매출입니다.

🔴 정부 보조금 → 매출 아님 (제외)
🟢 고객에게 판매한 금액 → 매출 (포함)
Q
달성률이 100%를 초과해도 되나요?
네, 가능합니다. 목표 10명 대비 실적 15명이면 150%로 표시되며, 「달성」 상태로 표시됩니다.
Q
연간 목표를 중간에 변경해야 할 경우는?
KPI 목표치 변경은 경영혁신본부 사전 협의 후 처리합니다. 임의 변경 시 전체 경영목표 집계에 영향을 미칩니다.
📋 담당자 → 경영혁신본부 협의 → 시스템 수정 순서로 진행
Q
